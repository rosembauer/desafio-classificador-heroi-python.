# 🛡️ Classificador de Nível de Herói em Python

Desafio prático desenvolvido para o bootcamp da [DIO](https://www.dio.me/).

## 📌 Objetivo
Classificar o nível/patente de um herói com base na sua quantidade de experiência (XP) utilizando variáveis, operadores, laços de repetição (`for`) e estruturas condicionais (`if/elif/else`) em Python.

## 🛠️ Tecnologias Utilizadas
- Python 3
- Git & GitHub

## 🚀 Como Executar
1. Certifique-se de ter o Python 3 instalado.
2. Execute o script no terminal:
   ```bash
   python main.py
